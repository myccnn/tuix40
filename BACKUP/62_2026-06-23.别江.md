# [2026-06-23 别江](https://github.com/myccnn/tuix40/issues/62)

上世纪90年代，何伟到涪陵师专任教，写下了江城。20年后他到川大任教，这下了这本别江。江城改改还能出版，这本就不用期待简中了，就算出版了也会失去可读性。他和他老婆11年去开罗－阿拉伯之春，16年回美国－川普当选，然后19年下半年来天朝……在书中他串联起了前后两代学生，以此来描绘时代的变迁停滞与倒退。他把两个女儿送进公立小学，并完整经历了清零三阶段的前两个，但在第三阶段开始之前未能被续聘。何伟可以说比大多数天朝人都更了解天朝，并且得益于他背后那个国际上比国内强势的祖国，让他在这个国内比国际上强势的国度游刃有余。天朝的不可能三角，understand / live in / love，任何人都只能从中最多取两样，何伟也不例外。
